# Clock designs

100 live clock designs, each a single HTML file with plain HTML, CSS and JavaScript. Every design shows the current time and date, fits on one screen without scrolling, and works offline with no build step, server or external dependencies.

All 100 designs were generated by Claude (Anthropic), using the Claude Opus 5.5 model in Claude Code.

## Browse

Open `index.html` in a browser. It lists every design with a live preview:

- Click a card to open that design full screen.
- 👍 / 👎 mark designs you like or don't. Disliked cards are greyed out.
- Filter by liked, disliked or unmarked, and use "Copy marks" to export your picks.
- Pages show 20 designs by default; choose 8, 20, 50 or 100 per page.

Marks and paging settings are saved in your browser's `localStorage`.

## What's inside

```
index.html          gallery of all designs
designs/            the 100 designs, 001-… to 100-…
simple/             the original single-file flip clock and its design plan
```

The designs range across:

- **Analog:** classic, Bauhaus, cuckoo clock, skeleton gears, 24-hour dial, pocket watch, grand complication
- **Digital displays:** seven-segment, dot matrix, nixie tubes, VFD, LCD watch, split-flap board, odometer, e-ink
- **Words and symbols:** word grid, sentence, Roman numerals, binary, BCD, Morse, Braille, tally marks, abacus, Maya numerals, Japanese kanji
- **Other time systems:** Unix epoch, Mars time, Chinese two-hour periods, sundial, world clocks, world calendars
- **Objects and scenes:** hourglass, candle, clock tower, lighthouse, Ferris wheel, aquarium, snow globe, metronome, lava lamp, vinyl record, car dashboard, cassette tape, heart monitor, receipt, newspaper, code editor, terminal
- **Generative:** particles, digital rain, flow field, zen garden, phyllotaxis, isometric blocks

Some designs have their own settings (colours, 12/24-hour, city lists, case metal and so on), saved in `localStorage`.

## Simple flip clock

The project started as a single dark-themed flip clock, now in `simple/index.html`. Its design plan is in `simple/docs/plans/flip-clock-plan.md`.
